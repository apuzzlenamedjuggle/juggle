How colors flow into other elements
Active cursor underline — uses today's J-letter color (first in rotation). Changes daily with the logo.
READY button — uses today's J-letter color as background, or a full 6-color gradient bar beneath it.
Pregame theme label — today's J-letter color for the theme text.
Achievement ribbons — each badge has its own fixed color (periwinkle, pink, lavender, green) — independent of daily rotation.
Confetti — always pastel rainbow (not tied to daily rotation).
Berry confirmed letters — fixed, not tied to daily rotation (see §D below).
READY button — two options for color use:
Option α — solid J-color
Option β — rainbow gradient underline on black
Option γ — black, clean (colors only in logo)

Confirmed Letter States
Two states: (1) a letter confirmed in the active word — shown in Berry so it reads as "locked in, you got this one right." (2) after the whole word is solved — those same letters fade to a transparent pink so five completed rows of bold Berry don't create visual noise at the bottom of the screen.
All five rows — mid-game (words 1–3 solved, word 4 active)
